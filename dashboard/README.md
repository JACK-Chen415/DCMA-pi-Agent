# DCMA 电机监控展板

本目录是可独立复制、安装和运行的监控展板项目，包含完整页面、数据库只读接口、共享类型、静态资源和测试。前端为 React / TypeScript / Vite / Tailwind，后端为 Node / MySQL，只查询 `dcma` 库的五张已确认表。无需启动 Pi SDK，也不依赖仓库中的 `packages/web/`。

页面采用白色侧边栏、蓝色选中态与浅色数据面板，六个监控页面只显示“查看设备”选中的一台电机；系统配置独立保存本机配置。正式页面只显示接口查询结果，不会以开发样例替代数据库。

页面统一卡片边框与间距、标题层次、数字字体和44px高的表单控件。时间信息分组显示，明细表使用隔行底色与固定表头；窄屏调整导航和卡片列数。

页面参考截图拍摄于2026年10月11日，不包含之后新增的系统配置、图表工具和近期事件列表。当前项目尚未部署在线服务。

## 启动

需要 Node.js 22.18 或更新版本（含 npm）、可访问的 MySQL 数据库和只读账号。获取公共仓库的 `dashboard` 分支后，在本目录安装依赖；如果已经取得项目，直接进入它的 `dashboard` 目录：

```powershell
git clone --branch dashboard --single-branch https://github.com/JACK-Chen415/DCMA-pi-Agent.git
cd DCMA-pi-Agent/dashboard
npm ci --ignore-scripts
if (-not (Test-Path database/.env)) { Copy-Item database/.env.example database/.env }
```

编辑 `database/.env`，填写 `MYSQL_HOST`、`MYSQL_PORT`、`MYSQL_USER`、`MYSQL_PASSWORD`，保持 `MYSQL_DATABASE=dcma`。示例中的 `127.0.0.1` 代表本机数据库，远程数据库需填写实际地址；学校数据库需要校园网或 VPN。账号密码由后端读取，不进入前端。配置修改后重启后端，不要覆盖已有 `.env` 或将凭据提交到 Git。

数据库需要已有的 `dcma.real_data`、`real_data_01`、`real_data_02`、`real_data_03`、`real_data_04` 表及采样记录。模拟表也是已入库的数据，并非页面自动生成。表需要记录编号 `id`、采集时间 `timestamp`、`device_name`、`inverter_name`；历史异常接口还需 `fault_code`、`alarm_code`。完整原始字段及显示映射见 [dashboard-types.ts](database/dashboard-types.ts)。缺表、缺必要字段或混入多个设备时接口会明确提示。项目不包含数据库备份或建表迁移，不会自动创建表、写入采样或用样例替代真实查询。

配置完成后，在两个终端分别进入这个项目的 `dashboard` 目录并运行：

```powershell
npm run dev:database
```

```powershell
npm run dev:frontend
```

打开 <http://127.0.0.1:3000>。前端将 `/api/database` 转发到本机 `3001` 的后端，两个服务仅监听本机；分别按 Ctrl+C 停止。若同时运行原工作台 `packages/web/`，它的默认3000端口会与展板冲突，应先停止其中一个服务。

依赖在本目录统一安装，前后端无需分别安装；单独复用时完整复制本目录，包括 `package-lock.json`、两个子项目及资源即可。`frontend/reference/` 是旧布局参考，保留来源说明，不参与编译，也不是运行依赖。

## 页面操作与数据规则

- “数据查询”与“历史异常查询”的开始、结束时间使用日期选择和固定24小时时分秒输入；可输入 `18:30:00` 或 `18:30`，不使用上午/下午或AM/PM。选日期时默认 `00:00:00`，结束时间旁的“现在”可填入当前北京时间，开始时间手动选择；填入不自动提交，仍需点击查询。
- 侧边栏菜单：设备概览（运行快照与29字段完整参数）、实时数据（趋势、六个仪表、近期事件列表和图表工具）、运行指标（18项数值按运动、电气、功率、温度、负荷分组）、故障与报警（当前代码、全历史事件、时间范围查询、汇总、分布与代码采样记录）、采样明细（29字段原始记录，默认展开）、数据查询（北京时间范围、历史趋势与采样明细分页）、系统配置（八个子菜单，通信配置可编辑并保存到当前浏览器）。默认打开实时数据；菜单支持地址片段与浏览器后退，切页回到顶部，保留设备、来源和采样条数选择。运行指标中的“查看趋势”跳转到对应曲线。
- 选择“查看设备”后，全页只显示对应电机的数据，不同时展示其他电机概览或来源警告。电机 1 默认模拟数据，可改为历史真实采集；电机 2～4仅有模拟数据，来源栏显示“模拟数据”并禁用切换。返回电机 1 时保留它此前的来源选择。
- 设备概览的“完整参数”按设备信息、采样信息、运动、电气、功率、温度、负荷参数、故障与控制分成8组，保留全部29项原值；桌面双列分区、窄屏单列，标题下不再显示字段数量说明。
- 故障与报警页的历史事件独立读取所选电机、来源的全部数据库采样，不受50/100/200条窗口限制，刷新后可重新生成，前提是原始历史仍保留。连续同码合为一次事件，首次观察非零为开始，首次观察归零或换码为结束；缺失代码不会作为恢复，故障和报警独立计算。最早历史记录已经异常时标记“最早观察时间”；未观察到结束时保留“未结束”，只显示已观察跨度，不使用当前墙钟推算。实际发生/恢复时刻受采样间隔限制。按北京时间选择起止范围，匹配所有与范围重叠的事件，保留完整起止时间；支持全部时间、每页50条、历史汇总与代码事件分布；分布独占一行，已移除重叠的历史异常时段图，起止时间与持续时间保留在历史记录表中。历史每30秒检查，或点击“查询异常”。下方代码采样表仍使用最近窗口，可按类型和代码文字筛选、重置；设备/变频器列与原始代码保留。切设备或来源清空旧历史及筛选，不混设备。
- “历史代码分布”下增加“故障/报警时长（分）”蓝色条形图，按代码和故障/报警类型分别累计当前筛选结果的完整事件跨度，分钟保留最多两位小数，悬停数字可查看精确跨度。未结束事件使用最后观察到该代码的采样时刻，不按当前时间增长；单点事件为0分钟。汇总在完整历史遍历时生成，不受50条明细分页限制；范围筛选仍匹配重叠事件并保留完整跨度。

- 非零故障码显示红色，非零报警码显示深黄色；零值只显示0，和缺失值保持默认颜色。运行卡片、完整参数、代码记录与采样明细使用相同规则，代码文字保持原值。
- 历史异常表有事件，而代码采样表筛选后显示0条时，先核对两个范围：前者读取全部历史，后者仅筛选最近50/100/200条采样。输入代码不查询全部历史，点击“重置筛选”恢复近期全部记录。
- 监控页已移除卡片、分组、图表与表格的辅助说明和页脚规则提示，单位放在字段名称后。查询状态、采样条数、截断、错误与空数据提示仍显示；原“数据说明”页已移除。
- 六个仪表单位统一放在标题的中文括号内，例如“实际转速（rpm）”；下方只显示读数，移除底部“量程／采样范围”文字，刻度与无障碍范围描述保留。
- 设备概览加入电机与变频器插图；本地SVG沿用蓝青配色，适配窄屏，仅作装饰，不表示实际设备外观或实时状态。
- 趋势默认设定/实际转速对比，可切换转矩对比或全部 18 个数值字段单项查看。采样条数为 50 / 100 / 200，默认 100。时间升序；缺失点断线，不补 0。
- 悬停查看北京时间、毫秒、记录编号和各曲线值；Tab 聚焦图表后用左右箭头查看相邻采样，Home / End 到首尾，Esc 关闭提示。采样明细支持 Enter 展开。
- 采样趋势右侧增加三个图标按钮：下载图表将当前曲线保存为1600×560的PNG，包含设备/来源、采样时间范围、指标及单位；放大查看使用浏览器原生全屏，支持退出按钮；数据视图显示当前曲线对应的北京时间（毫秒）和所选指标，不补0、不裁剪原始数值精度。实时采样刷新时表格与曲线同步；切设备、来源或指标后重置视图。历史查询页同样支持，只针对当前页。下载失败或浏览器拒绝全屏有提示，空曲线/全缺失数值禁用下载。
- 实时页新增“事件列表”，复用历史事件的连续同码合并规则，在当前最近50/100/200条采样中生成故障/报警事件；最多显示最新50个，日期和时间为首次观察时刻，不代表设备精确发生时刻，窗口起始已异常时明确标记。记录为0或缺失不显示异常代码事件，缺失不冒充恢复；点击“查看历史故障与报警”进入全历史查询。环境温度按用户最新确认不添加。

- “数据查询”是独立页面（`#query`），输入北京时间起止时间后手动查询，包含起止时刻；时间编辑不会提前请求。每页50/100/200条，按采集时间降序、编号降序分页，趋势按当前页采样时间升序展示，不代表整个时段的完整曲线；显示总条数、查询范围和页码。历史页不显示实时仪表，不自动刷新，离开该页取消历史请求并恢复近期采样查询；切设备或来源清空范围及旧结果。“返回实时”进入实时数据页并恢复3秒检查。
- 其他页面打开和切设备、来源、采样条数立即请求。每 3 秒自动检查，查询未结束时跳过，手动刷新查询期间禁用。切换取消旧请求并拒绝旧响应回写。
- 同一选择刷新失败保留上次成功结果并提示；首次或切换失败不展示其他设备的旧值。空表、无效时间、截断均有提示。
- 仪表按用户参考图固定五项左右极值：实际转速−1500～1500 rpm、实际电流0～3.3 A、直流母线电压0～1200 V、变频器/电机温度均0～150 °C；刻度不再随采样窗口变化。用户确认实际转矩仍保留原有N·m采样范围，恒定值扩展为非零跨度；不改为参考图中的转矩利用率百分比。超量程时仅指针停在边界，数字保留实际读数，缺失显示“—”且不画指针；固定刻度仍显示。显示量程不代表安全阈值。
- 单位参考用户截图：转速 rpm、电流 A、转矩 N·m、电压 V、功率 kW、温度 °C、负荷率 %，同类字段统一标注，不进行数值换算；脉冲频率按 kHz 标注。卡片读数最多显示4位小数，参数和明细保留原值，有效0、负值及 `air_intake_temp=-200` 保留。`status` 和 `system_run_time` 在页面各处隐藏，数据库与接口仍保留31个原始字段，页面展示其余29个字段；字段名称仅显示中文及单位。故障码、报警码的零值仅显示“0”，不附加“正常”文字，非零保留原始代码，缺失显示“—”，控制字/状态字不解释。
- 采集时间、入库时间、接口查询时间分别显示；日期文本暂按北京时间解释，13 位时间戳按毫秒解析。无效采集时间不进入曲线，不用入库时间替代。
- 接口连接、数据来源和采集更新状态分别展示。“检测到新采样”来自相邻成功查询的记录变化；“本次无新采样”不等于连接失败。当前真实表为 2026-01-14 的历史采集。

## 只读接口

| 接口 | 用途与限制 |
|---|---|
| `GET /api/database/dashboard?table=real_data_01&limit=100` | 五个来源摘要、所选最新值、近期采样、原始记录和查询时间；limit仅支持50/100/200，响应上限512000字节，过大时明确截断较早记录 |
| `GET /api/database/code-history?table=real_data_01&page=1&from=2026-10-08T00:00:00.000Z&to=2026-10-10T00:00:00.000Z` | 所选来源全部历史生成的故障/报警事件；from/to可省略，使用标准ISO UTC时间；事件重叠筛选，50条/页及筛选结果汇总；codes中的durationMs为各类型/代码匹配事件的累计跨度（毫秒），page支持1～1000 |
| `GET /api/database/sample-history?table=real_data_01&limit=100&page=1&from=2026-10-10T00:00:00.000Z&to=2026-10-11T00:00:00.000Z` | 所选来源采集时间范围内的原始采样；from/to必填标准ISO UTC，包含边界，仅有效采集时间参与；limit为50/100/200，page为1～1000；返回当前页趋势/明细及总数 |
| `GET /api/database/catalog` | 配置与连接状态、已知表的字段结构；`?refresh=1`重新检查 |
| `GET /api/database/rows?schema=dcma&table=real_data_01&limit=20` | 旧原始预览接口保留，1～200行/64KB；不作为趋势数据接口 |

`real_data_01`～`04`对应电机1～4的模拟表，`real_data`对应电机1历史真实采集。展板固定只读 `dcma`，不接受任意SQL或写入。原展板使用5秒SQL超时、15秒请求时限和18秒浏览器超时；历史接口以只读事务流式遍历所选来源的采集时间、编号和代码，不把全部采样放进响应，SQL55秒/请求60秒/浏览器65秒超时，支持取消。采样范围接口在只读事务中统计数量并读取当前页，同样使用SQL55秒/请求60秒/浏览器65秒超时及取消；最多1000页，超过提示缩小范围或增加每页条数；当前页超过512000字节会拒绝返回，避免截断后跳过记录。所有查询保留参数绑定。发现一个来源有多个设备/变频器时停止混合展示；无设备标识记录被排除。
