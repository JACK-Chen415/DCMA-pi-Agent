# Changelog

## [Unreleased]

### Added

- 结构化交付新增四类定性结论（conclusion、process、hypothesis、recommendation），只接受不带数值的定性文字，程序校验后与数据结论一起发布；结论先行不再被模板吞掉。
- `lookup_fault_code` 并入随附 RAG 语料：S120 精确查码直接命中页码与原文；G120 等无专用手册的型号返回跨系列条目并标注 `reference_only`。
- `search_fault_knowledge` 在查询点名的设备系列没有随附手册时，回退到冲突来源并输出 `reference_only`、`retrieval_log.family_fallback`，正文自动附加适用性提醒。
- 新增端到端答案质量评测 `answer-evaluation.ts`：8 个固定问题检查结论先行、状态规则、手册出处、参考标注、澄清不取数、对比与图表交付，输出逐项结果与原始回答。
- 新增环境变量 `DCMA_RUNTIME_DIR`，可把运行时目录指到服务目录之外做隔离评测。

### Changed

- 多项诊断回答按章节展示，合并同一证据的测点统计，并将候选原因和核查动作排成列表。聊天表格支持横向滚动及放大预览。

- 模型推理档位默认由 `low` 改为 `medium`；`low` 在 2026-11-15 对照中把分析收敛成一行模板交付。
- 系统提示词重写为“结论先行、证据随后、边界明确”的短提示（6.5k 字压到 4k），正文数值改为 4 位有效数字、单位不加括号，去掉固定 emoji 和整段免责堆叠。
- 原有四个模拟表补上观测状态规则 `dcma_observed_v1`（status 0/42 判为运行，非厂家定义），状态评估并入 `build_diagnostic_evidence`。
- 综合诊断证据包超过 20000 行原始明细时自动降级为数据库聚合统计加流式事件，质量检查标记未执行，不再整体失败；超 62KB 的工具结果先降采样汇总行和明细再拒绝。
- 多窗口结论按时间分段标注并合并同题小节，不再因“混用窗口”拒绝同一设备的分段结论；时间戳类原始记录渲染为北京时间，浮点保留 4 位有效数字。

### Fixed

- 综合诊断结果超出 62 KB 时，缩减嵌套的事件和趋势预览，保留全时段统计与事件汇总。图表继续使用原查询结果。近期采样的范围说明单独显示。

- 修复 Skill 预加载测试与按需加载实现不一致导致的 `skills.test.ts` 失败；断言改为“常驻只有名称与描述、正文经 load_skill 取回”。
- 修复定性文字中合法设备标识（F07900、g120_sim_v1）被误判为数值导致的交付反复失败；仅纯数值、时刻和持续时间被拒绝。
