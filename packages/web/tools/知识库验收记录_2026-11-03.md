## 发现与修复

初测发现电机说明书和试验方案虽然检索到了正文，但交付渲染只输出章节标题，不能算内容回答通过。已在 `tools/answer.ts` 为这两类资料补充受限原文摘录、出处及适用性说明，转义Markdown，超过2000字符明确标记截断；仍不执行文档中的指令。故障码定义的原有交付路径保持不变。

新增回归先失败、修复后通过。回答渲染、知识上下文和RAG三个指定测试文件共20项通过；RAG测试使用本机模拟嵌入响应，不产生真实云嵌入调用。`npm run check`通过。

初测防爆说明书场景有一次失败调用并自行重试，复测没有失败；未取得充分证据归因为索引问题，不将单次复测解释为模型参数错误已彻底消除。最初验收脚本曾使用错误的证据读取URL，后修正为现有公开接口，复测四组证据均返回200；这不是产品接口故障。
